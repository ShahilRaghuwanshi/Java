# 📌 Wrapper class

Java is not a pure object oriented programming language[cite: 4]. Even though java is not a pure object oriented programming language Softwares developed in java can be made pure object oriented by making use of wrapper class instead of primitive data types[cite: 4].

Eg. :-[cite: 4]

* `char a = 'x';` &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; `a | x`[cite: 4]
* `byte b = 10;` &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; `b | 10`[cite: 4]
* `short c = 20;` &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; `c | 20`[cite: 4]
* `int d = 30;` &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; `d | 30`[cite: 4]
* `long e = 40;` &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; `e | 40`[cite: 4]
* `float f = 3.147f;` &nbsp;&nbsp;&nbsp;&nbsp;&nbsp; `f | 3.147`[cite: 4]
* `double g = 33.3384;` &nbsp; `g | 133.3384`[cite: 4]
* `boolean h = true;` &nbsp;&nbsp;&nbsp;&nbsp; `h | true`[cite: 4]

*(value store in data type)*[cite: 4]

> **Note:** (Any language has to be called as pure object oriented programming language then everything that is present in the language Should object - because of primitive data types java is not pure oop)[cite: 4]
